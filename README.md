# ✦ Искра

**Красивый, плавный и лёгкий лаунчер для Windows 11 с темами, которые меняют не только лаунчер, но и всю Windows.**

Искра — это:
- окно-поиск по горячей клавише (по умолчанию **Alt+Space**) + значок в трее;
- замена меню «Пуск» по клавише **Win** (перехват низкоуровневым хуком, как в PowerToys);
- полноэкранный **стартовый экран** с живыми плитками и перетаскиванием;
- 13 выразительных тем, которые меняют **шрифты, формы, материалы, анимации, звуки, курсоры, обои** — и применяются **ко всей Windows**;
- **значки в форме темы**: капля, круг, сквиркл, шестиугольник, ромб, звезда, лист, клякса, пиксель и другие — в лаунчере, плитках и (по желанию) в самой Windows;
- редактор тем;
- оформление без нарушения прав: только OFL-шрифты, собственные названия, никаких логотипов и проприетарных ресурсов.

Весь интерфейс на русском, с переключением на английский.

## Стек и почему
**.NET 10 + WPF + Win32 DWM API.** Почему не WinUI 3: WPF даёт самый прямой доступ к `DwmSetWindowAttribute`
(Mica/Acrylic, скругления, тёмная рамка) и к низкоуровневым хукам/глобальным горячим клавишам, меньше весит в простое,
не тянет MSIX-упаковку и спокойно ставится **per-user без прав администратора**. Композиционные анимации WPF идут на
частоте монитора (144 Гц поддерживается), а в простое (окно скрыто) ЦП ≈ 0 %.

## Возможности поиска
- мгновенный нечёткий поиск (точное → префикс → аббревиатура → подстрока → подпоследовательность → опечатка);
- **раскладка**: `ntktuhfv` → `телеграм`, `ыеуфь` → `steam`;
- **транслитерация**: `telegram` ↔ `телеграм`;
- приложения (ярлыки «Пуска» и Store через AppsFolder), файлы, страницы «Параметров» (`ms-settings:`),
  калькулятор, веб-поиск, системные команды (блокировка, сон, перезагрузка, корзина, скриншот…);
- обучение на выборе (frecency + привязка к запросам), недавние и частые;
- закреплённые элементы с перетаскиванием.

## Темы (13)
Слюда · Плитки · Прожектор · Неон · Тетрадь (рукописная кириллица) · Терминал · Сияние · 8 бит · Минимал · Космос · Закат · Библиотека · Сакура.
См. `screens/` — у каждой свои шрифты, цвета, анимации, звук, курсоры и обои. Плюс редактор своих тем.

## Что тема меняет в самой Windows
- тёмный/светлый режим, акцент, прозрачность, акцент на заголовках и панели задач;
- обои (и слайд-шоу), картинку экрана блокировки;
- указатели мыши (генерируются приложением), звуковую схему, интервал значков рабочего стола;
- материал/углы/рамку окон (Проводник и др.) через DWM — без внедрения кода в чужие процессы;
- стиль контекстного меню (классическое/новое), компактный вид Проводника, выравнивание и размер панели задач;
- классические цвета `Control Panel\Colors` (старые окна/диалоги), метрики окон (полоса прокрутки, высота заголовка, отступ рамки);
- значки папок, «Этот компьютер» и корзины — в форме темы (через реестр, обратимо);
- значки ярлыков рабочего стола и «Пуска» в форме темы (с резервной копией исходного значка);
- **экспериментально** — шрифт интерфейса Windows (нужны права администратора, с точкой восстановления и откатом в одну кнопку).

### Необязательные глубокие интеграции (ВЫКЛ по умолчанию)
Для стилизации панели задач, «Пуска», центра уведомлений и контекстного меню **сверх возможностей реестра**
Искра может (по явному согласию и полностью обратимо) установить официальный открытый **Windhawk**
(windhawk.net, тихая установка `/S /STANDARD`, настройка модов через `windhawk-cli`) и применить открытые
моды-стилизаторы под тему; отключение модов или удаление Windhawk возвращает всё назад. Аналогично предусмотрен
путь для msstyles через SecureUxTheme — строго по согласию, с предупреждением и откатом. По умолчанию всё это выключено.

### Чего сторонняя программа изменить не может (честно)
- внутренний вид приложения «Параметры», Microsoft Store и других WinUI/UWP — их рисует сама Windows;
- встроенную панель задач Windows 11 нельзя перекрасить без внедрения в Проводник — Искра предлагает свою
  панель-док, прозрачность системной панели, а для полной стилизации — необязательный Windhawk (см. выше);
- меню Win+X, центр уведомлений, быстрые настройки и экран входа остаются системными.

## Надёжность
- **Безопасный режим**: удерживайте **Shift** при запуске (или он включится сам после сбоя) — минимум эффектов,
  непрозрачный фон, программная отрисовка, тема к Windows не применяется.
- **Самовосстановление** настроек и тем: битый JSON чинится из резервной копии/значений по умолчанию;
  цвет текста гарантированно контрастирует с фоном (никакого «белого по белому»).
- Материал (слюда/акрил) применяется только когда он реально рисуется; иначе окно непрозрачное и читаемое.

## Безопасность
- перед первым применением сохраняется снимок «как было»; кнопка **«Вернуть Windows как было»** и отдельный
  скрипт `%LOCALAPPDATA%\Iskra\Вернуть-как-было.ps1` (только .NET Registry API, без reg.exe/regedit);
- перед изменениями уровня администратора создаётся точка восстановления;
- не трогает и не обходит «Стоп-экран» (`C:\Program Files\StopScreen`) и его политики; не отключает защиту Windows;
- не патчит и не заменяет подписанные системные DLL;
- установка per-user в `%LOCALAPPDATA%\Iskra`, автозапуск через ярлык в «Автозагрузке», **без прав администратора**.

## Установка
- **Установщик** `Iskra-Setup-<версия>.exe` (Inno Setup, per-user, без администратора), либо
- **Портативно** `Iskra-Portable-<версия>.zip` — распакуйте и запустите `Iskra.exe`.

## Сборка
```
dotnet build Iskra.slnx -c Release
dotnet test tests/Iskra.Core.Tests
dotnet publish src/Iskra.App -c Release -r win-x64 --self-contained -o publish
```

## Горячие клавиши
- **Alt+Space** — поиск · **Win** — меню «Пуск» Искры · **Alt+Shift+Space** — стартовый экран
- Enter — открыть · Ctrl+Enter — от администратора · Shift+Enter — расположение файла · Ctrl+P — закрепить
- `? запрос` — сразу веб-поиск

Все сочетания настраиваются (с проверкой конфликтов).
